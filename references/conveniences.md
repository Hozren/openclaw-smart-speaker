# Повседневные функции

Копируй scripts/amenities.py вместе с остальными scripts/*.py; обнови установленный speaker_music.py из того же коммита. Сохрани исходники приложения для отката. Останови единственный listener перед копированием, затем запусти прежний unit. Не меняй голос, модели, устройства и scope автозапуска ради обновления.

## Команды

- Без имени: «громче», «тише», «сделай тише», «громкость 30 процентов». Vosk перехватывает точные фразы до Whisper/агента. Шаг 10, диапазон 0–100; поддерживаются числа цифрами и русские десятки. Это громкость mpv нашей речи и музыки, не системный микшер и не посторонние приложения.
- «Луна» в начале распознаваемой фразы: тихий короткий сигнал готовности, музыка приглушается до 15 или ниже, если исходная громкость ниже. Во время ответа сохраняется приглушение. После завершения/ошибки восстанавливается выбранная громкость. Пауза речи снимает приглушение, продолжение возвращает его. Защитный таймаут активации — 30 секунд; он не отменяет запрос.
- «Луна, включи ночной режим» / «выключи ночной режим». Ограничение 30%, сигналы выключены. «Ночной режим по расписанию» — ежедневно 23:00–08:00 по часовому поясу процесса, без cron и без агента. По умолчанию режим выключен. При ручном увеличении ночью ограничение сохраняется.
- «Луна, что играет?» — локальные метаданные. «Повтори» / «повтори песню» / «повтори трек» — текущий активный или приостановленный трек с начала; законченный трек не загружается заново этой командой.
- «Луна, включи другую», «следующая песня», «включи ещё этого исполнителя» — агент получает title/query/artist от CLI и выбирает новый запрос. Это не готовая очередь или рекомендательный сервис; доступность исполнителя зависит от метаданных, агент уточняет, если информации мало.
- «Луна, запомни это …», «запиши заметку …», «добавь молоко в покупки», «что в списке?», «прочитай заметки». Обрабатываются локально после Whisper и wake/follow-up, не уходят агенту. Подтверждение только после commit SQLite. Один список покупок; нет таймеров, удаления, облачной синхронизации или неявного сохранения предыдущего разговора.

Новые команды, кроме громкости, требуют имени или активного 15-секундного окна. Локальные ответы проходят обычную управляемую озвучку. Занятый ответ не заменяется новым запросом; stop/resume/volume доступны независимо. Обычная речь не хранится; сохраняется только явно продиктованное содержимое заметок/покупок.

## Настройки и данные

VOICE_DATA — постоянный каталог, default ~/.local/share/openclaw-speaker-data. SQLite speaker.sqlite3, каталог 0700, файл 0600. Резервируй каталог отдельно от исходников, не коммить. VOICE_CUES=0 выключает сигналы. VOICE_MUSIC — путь к CLI, default speaker-music из PATH. Сервис музыки и listener должны использовать одинаковый XDG_RUNTIME_DIR.

Параметры volume/night сохраняются в SQLite и переживают рестарт. Расписание использует локальную временную зону процесса; если нужна другая, задай TZ в unit. Ночной лимит относится только к нашим плеерам, не является ограничением системного уровня. Файл speaker-operations/audio-policy.json передаёт стартовую громкость новым плеерам; не содержит команд. Политика сверяет PID/start stamp и свежесть. Listener обновляет живые mpv примерно каждые 300 мс.

## Проверка и ограничения

Запусти unittest discover -s tests -v. Есть проверки сохранности заметок, ошибок диска, запрета случайных команд, реального mpv с null-output для duck/restore/night. Для акустической проверки используй benchmark_controls.py на синтезированных «тише», «громкость тридцать процентов» и негативной фразе. Это не проверка живого микрофона.

Сигнал активации зависит от того, когда Vosk узнал имя; это не отдельная wake-word нейросеть. Если быстрый канал выключен, сигнал появляется только после Whisper. Эхоподавления нет: открытые динамики могут вызвать самораспознавание; для первых проверок используй гарнитуру. Отказ воспроизведения сигнала не означает отказ основного запроса.
