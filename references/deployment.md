# Развёртывание и ограничения

## Оборудование
Практический стартовый ориентир, не сертифицированный минимум: современный x86-64 CPU с четырьмя потоками, 8 ГиБ RAM и 5 ГиБ свободного диска для окружения и моделей. На более слабом хосте замерь Whisper tiny/base вместо small и качество русской речи; на ARM проверь наличие совместимых wheels. GPU для этой CPU-связки не обязателен. Скорость определяет измерение на целевом устройстве, не объём RAM сам по себе.

Минимальный проверяемый аудиокомплект — USB-гарнитура с микрофоном и аппаратным mute. Для работы в комнате удобнее USB-спикерфон с микрофоном и заявленным аппаратным эхоподавлением; проверь качество на реальном расстоянии. Это рекомендация класса устройства, не гарантия совместимости модели. Проводной USB предпочтителен как простой старт; Bluetooth-профили могут менять качество при включении микрофона. Проверь кабель, питание, стабильность USB. AUX умной колонки не означает передачу её микрофонов; назначение конкретного разъёма сверяй с документацией производителя.

Используй pw-dump и mpv --audio-device=help; если pactl отсутствует, не делай его обязательным. Запись: pw-record с выбранным --target, --rate 16000, --channels 1, --format s16; сначала проверь help установленной версии. Демон читает raw PCM со stdout. Для тестового файла используй поддерживаемый формат и остановку записи, затем посчитай RMS/peak. Gain применяй до VAD с ограничением int16. Снижай gain при клиппинге.

## Установка
Узнай пакетный менеджер ОС и доступные пакеты Python venv, PipeWire CLI, WirePlumber, mpv. Установи недостающее штатным способом. Создай приложение и venv под пользователем, который должен обращаться к Gateway и звуку. Используй абсолютный Python из venv в сервисах.

Установи CPU PyTorch по официальному https://pytorch.org/get-started/locally/ (для совместимой Linux-сборки индекс https://download.pytorch.org/whl/cpu), затем numpy, faster-whisper, webrtcvad-wheels. Поддерживаемый локальной проверкой faster-whisper 1.2.1 использовался с av==16.0.1: это устранение наблюдавшейся несовместимости av19 metadata_errors, не вечная универсальная фиксация. При других версиях проверь реальное декодирование WAV. Выполни pip check и запиши рабочие версии. Не тащи чужой полный pip freeze на другой Python/архитектуру.

Whisper: https://github.com/SYSTRAN/faster-whisper. Загрузи модель small из официального опубликованного репозитория Systran/faster-whisper-small в VOICE_ROOT/whisper-small через поддерживаемый Hugging Face downloader. Проверь полноту модели реальным распознаванием. Для другой модели меняй каталог/код осознанно: текущий шаблон использует whisper-small.

Silero: https://github.com/snakers4/silero-models и его models.yml.
Проверенная русская модель: https://models.silero.ai/models/tts/ru/v5_6_ru.pt
Путь назначения: VOICE_ROOT/silero/v5_6_ru.pt.
Проверенный SHA256: 04cc9b1d08ce38bcaa9d02c488d80d3e6806d17f7eaa7c95982f36a3cbf50b2e.
При несовпадении останови загрузку модели в Python, сверь версию и официальный источник; не переписывай ожидаемый хеш автоматически. Модели torch.package исполняют Python, поэтому используй доверенный официальный источник и сохрани проверенный файл. Лицензию модели/условия использования проверь по официальной документации для выбранной версии. Веса не входят в пакет skill.

Модель загружается через torch.package.PackageImporter(...).load_pickle('tts_models','model'), переводится на CPU и синтезирует apply_tts(text=..., speaker=..., sample_rate=24000, put_accent=True, put_yo=True). Поддерживаемые частоты модели: 8000/24000/48000. Все пять русских голосов входят в один файл. Сверь model.speakers; random, если возвращается, не отдельный стабильный голос.

## Параметры скриптов
VOICE_ROOT: корень моделей, venv может находиться внутри; default ~/.local/share/openclaw-voice.
VOICE_MIC / VOICE_SINK: реальные PipeWire node.name; обязательны для слушателя.
VOICE_AGENT: ID созданного агента, default voice.
VOICE_SESSION: отдельная стабильная сессия, default agent:<ID>:voice-speaker.
VOICE_WAKE: слово активации, default Луна. Текущий ASR и ответы русскоязычные.
VOICE_OPENCLAW: полный путь к CLI, default openclaw из PATH.
VOICE_GAIN: измеренное усиление, default 1.
VOICE_THREADS: потоки Whisper, default 4.
VOICE_FOLLOWUP_SECONDS: default 15.
Silero использует четыре CPU-потока в local_tts.py; скорректируй для слабого CPU и проверь задержку.

Запускай команды Python из venv с одним и тем же VOICE_ROOT:
python local_tts.py --list-voices
python local_tts.py --voice silero:baya --tts 'Первый голос. Проверка речи.' /tmp/voice-baya.wav
python local_tts.py --set-voice silero:xenia
python speaker.py --asr /tmp/voice-baya.wav
python speaker.py --self-test
python -u speaker.py

Для демонстрации нескольких голосов импортируй synth из local_tts и вызывай его в одном процессе: загрузка модели будет общей. Параметр voice='silero:NAME' одноразовый; постоянные настройки хранятся атомарно в VOICE_ROOT/tts-settings.json и перечитываются на каждый ответ. Piper присутствует только как необязательная совместимость адаптера; без установки его пакета и моделей эти варианты недоступны. --list-voices показывает поддержанные адаптером имена, а не проверку наличия файлов: для пользовательского каталога фильтруй по реально установленным моделям. Для русского Silero временный default xenia не заменяет этап пользовательского выбора.

## Интеграция OpenClaw
Перед настройкой прочитай установленную схему конфигурации, CLI help или используй системный инструмент OpenClaw. Не выдумывай CLI subcommands. Проверенная форма запроса:
openclaw agent --agent ID --session-key KEY --thinking low --message TEXT --json --timeout 180
Проверь поддержку флагов и формат ответа на целевой версии. Адаптер читает result.payloads[].text либо final; при другой схеме адаптируй ask(), не принимай пустой результат за успех. Поддерживаемый Node должен быть в PATH сервиса, а не только интерактивного shell. Неподходящий системный Node уже вызывал сбой реального voice-turn.

Для TTS есть провайдер tts-local-cli: по схеме установленной версии включи плагин, задай command абсолютным Python из venv, args с абсолютным local_tts.py, --tts, {{Text}}, {{OutputPath}}, outputFormat wav. Проверь передачу аргументов без shell-интерполяции. Gateway и колонка должны видеть один VOICE_ROOT. Если провайдер не передаёт env, используй небольшой launcher с фиксированным локальным VOICE_ROOT и exec; не вставляй текст пользователя в shell-строку.
Проверь через поддерживаемый RPC tts.convert и статус провайдера; команды openclaw tts/asr могут отсутствовать. Не включай автозвучание всех чатов ради отдельной колонки.
Документация: https://docs.openclaw.ai/tools/tts/configuration и https://docs.openclaw.ai/nodes/audio .

Этот пакет не устанавливает графический переключатель голоса. При отдельном запросе выбери нативный speech-provider plugin с реальным списком голосов либо отдельную страницу preview/apply; не обещай UI до проверки её работы.

## Проверки
Программный loopback не заменяет живой микрофон. Проверь: имя+вопрос; имя отдельно; продолжение внутри 15 секунд; отказ от активации без имени после таймаута; стоп; возврат USB; доступность Gateway после перезапуска. При недоступном аудиосервере шаблон ждёт, при отсутствии выбранного устройства не выбирает соседнее.
Скрипт не хранит записи и не логирует распознанный текст; реплики остаются в обычной сессии OpenClaw. Он не реализует dedicated wake-word engine, echo cancellation, стриминг и очередь возврата фоновых задач. Локальное прерывание речи и музыки реализовано после ASR: см. operations.md; требуется живая акустическая проверка. Все эти возможности требуют отдельной реализации и проверки.

Диспетчер: копируй все scripts/*.py вместе; прочитай references/operations.md (от корня skill). Микрофон теперь работает во время ответа, поэтому для открытых динамиков нужен внешний AEC.
