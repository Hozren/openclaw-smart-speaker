# OpenClaw Smart Speaker

Переносимый skill и исходники для русскоязычной умной колонки на Linux.

Микрофон → WebRTC VAD → локальный faster-whisper → агент OpenClaw → локальный Silero TTS → динамики.

## Возможности

- Проверка оборудования и рекомендации по минимальному комплекту.
- Установка Whisper и всех пяти голосов выбранной русской модели Silero: baya, kseniya, xenia, aidar, eugene.
- Демонстрация голосов и сохранение выбора пользователя.
- Отдельный быстрый агент: выбор модели по доступности в аккаунте и замерам.
- Настраиваемое имя активации, по умолчанию «Луна», только в начале фразы.
- Окно продолжения без имени: 15 секунд после ответа. «Стоп» ставит воспроизведение на паузу и закрывает окно.
- Общий выбор голоса для слушателя и OpenClaw Local CLI TTS.
- Настройка запуска при загрузке системы без GUI-логина.

## Требования

Linux, systemd, PipeWire/WirePlumber, Python venv, mpv, установленный и авторизованный OpenClaw с совместимым Node.js.

Практический стартовый ориентир: CPU с четырьмя потоками, 8 ГиБ RAM, 5 ГиБ свободного диска. Это не гарантированный минимум: скорость проверяется на целевом хосте. GPU не обязателен.

Для первого запуска рекомендуется USB-гарнитура с микрофоном. Для комнаты — USB-спикерфон с аппаратным эхоподавлением после проверки разборчивости на нужном расстоянии. AUX колонки сам по себе не передаёт её микрофоны компьютеру.

## Установка с помощью OpenClaw

```sh
git clone https://github.com/Hozren/openclaw-smart-speaker.git
```

Передайте агенту путь к клону и запрос:

> Прочитай AGENTS.md и SKILL.md. Настрой умную колонку: проверь оборудование, установи Whisper и Silero со всеми пятью русскими голосами, дай выбрать голос, создай отдельного быстрого агента, проверь живой диалог и настрой запуск без логина. Сохрани существующего основного агента и авторизацию. Перезагрузку согласуй отдельно.

Для постоянной регистрации skill используйте механизм установки skills вашей версии OpenClaw. Клон содержит SKILL.md в корне, но само клонирование не регистрирует skill.

Это процедура для агента, а не универсальный установщик одной командой. Скрипты копируются в отдельный каталог приложения; модели и рабочие настройки не хранятся в репозитории.

## Команды после установки

Используйте Python установленного venv, каталог скопированных скриптов и общий VOICE_ROOT:

```sh
export VOICE_ROOT="$HOME/.local/share/openclaw-voice"
python local_tts.py --list-voices
python local_tts.py --voice silero:xenia --tts 'Привет! Проверка голоса.' /tmp/voice-demo.wav
python local_tts.py --set-voice silero:xenia
python speaker.py --self-test
```

Для слушателя задайте VOICE_MIC, VOICE_SINK, VOICE_AGENT, VOICE_OPENCLAW и остальные параметры из deployment.md. Усиление подбирается по измерениям.

`--list-voices` показывает поддержанные имена, не наличие файлов. Piper необязателен и требует отдельной установки пакета и моделей. Временный default xenia не заменяет выбор пользователя. `--self-test` вызывает настоящего агента, но не проверяет физический микрофон и слышимость.

## Автозапуск и проверка

Следуйте [boot.md](references/boot.md). Системный Gateway предполагает системный unit от непривилегированного пользователя; для пользовательского Gateway допустим user unit с lingering. В обоих случаях аудиосервер и права устройств должны работать до входа человека.

Состояние `enabled` не доказывает работу без логина. Нужны согласованная перезагрузка без GUI-входа, проверка времени старта сервисов и реальный вопрос с подтверждённым ответом. Чистая установка и boot требуют приёмки на целевом хосте.

## Ограничения и приватность

- ASR/TTS локальны после загрузки моделей. Агент может использовать облачного провайдера.
- Имя активации определяется Whisper после распознавания, а не отдельным wake-word engine.
- Непрерывный микрофон и локальные pause/resume/stop через потоковый Vosk, без ожидания Whisper: см. [протокол операций](references/operations.md). Эхоподавления и потоковой озвучки нет; реальная задержка зависит от ASR.
- Нет встроенного графического каталога голосов и очереди озвучивания фоновых результатов.
- Обычные записи речи не сохраняются, распознанный текст не пишется в журнал слушателя. Реплики остаются в сессии OpenClaw; диагностический self-test выводит тестовые реплики.
- «Все голоса» означает пять голосов выбранной русской модели, не все языки и исторические версии Silero.

Веса моделей, Python-окружение, записи, токены и конфигурация аккаунта не входят в репозиторий. Модели скачиваются из официальных источников с проверкой хеша. Условия лицензий моделей и зависимостей проверяются отдельно. torch.package исполняет код модели — используйте проверенный источник.

```sh
python3 -m compileall -q scripts
```

Это проверка синтаксиса без моделей и оборудования. Интеграционные проверки описаны в SKILL.md; для разработки следуйте AGENTS.md.

## Музыка через yt-dlp

Отдельный [speaker-music skill](skills/speaker-music/SKILL.md) и простой CLI: разобранный агентом запрос → единый кэш → yt-dlp при промахе → mpv. Полная загрузка предшествует воспроизведению; повторный запрос играет без сети. Есть `play`, `pause`, `resume`, `stop`, `status`, JSON-ответы и фоновый проигрыватель.

Установка для выбранного голосового агента (Python 3.12+, python3-venv):

```sh
python3 skills/speaker-music/scripts/install.py --skill-dir /path/to/agent/workspace/skills/speaker-music
~/.local/bin/speaker-music play 'Artist - Song'
~/.local/bin/speaker-music status
~/.local/bin/speaker-music stop
```

Установщик всегда получает latest опубликованный release этого репозитория, а не локальную копию CLI. Проверяет SHA256 release asset, ставит актуальный yt-dlp в отдельный venv и недостающие mpv/ffmpeg через apt. На другом дистрибутиве зависимости ставятся отдельно. Для YouTube нужен поддерживаемый JS runtime: Deno или Node (при наличии Node CLI включает его явно). Ограничения YouTube/сети могут блокировать загрузку; cookies автоматически не извлекаются.

Одна директория кэша: `~/.cache/openclaw-music`, переопределение `MUSIC_CACHE` должно быть одинаковым для всех вызовов. `MUSIC_AUDIO_DEVICE` — значение из `mpv --audio-device=help`; без него используется системный выход. Установка выполняется под пользователем аудио, не root. Видимость skill и allowlist голосового агента настраиваются отдельно по SKILL.md.

Кэш индексируется по нормализованному запросу, медиа — по video ID. Автоочистки и очереди нет. Ducking реализован корневым слушателем. `stop` управляет только mpv этого CLI. Фоновый плеер не гарантирует голосовое прерывание на открытых динамиках.

Публикация: тег `music-vX.Y.Z` запускает workflow, тесты и выпуск `speaker-music.tar.gz` с `speaker-music.sha256`. SHA проверяет целостность, доверие основано на HTTPS и репозитории. Последующие latest releases должны сохранять эти assets для совместимости установщика.

Проверки без сети и аудио: `python3 -m unittest discover -s tests -v`. Документация зависимости: https://github.com/yt-dlp/yt-dlp .

## Локальное управление без агента

«Стоп» — пауза речи, иначе музыки. «Продолжи» — последнее приостановленное. «Останови музыку», «продолжи ответ» — адресные команды. «Отмени ответ» — подавить озвучку окончательно. Таймеров нет. [Протокол, CLI и приёмка](references/operations.md).

Быстрый канал требует Vosk и отдельную небольшую русскую модель. Установка, словарь и измерение задержки — в [operations.md](references/operations.md). «Стоп» зарезервирован для раннего срабатывания; адресуй командой «останови музыку».

## Удобства колонки

Приглушение музыки на обращение и ответ, сигналы готовности/ошибки, «громче/тише/громкость 30 процентов», ночной режим вручную или 23–08, «что играет/повтори», подбор другой песни с контекстом и локальные заметки/покупки. [Команды, установка и ограничения](references/conveniences.md). Громкость и stop/resume обходят агента; заметки подтверждаются после сохранения на диск. Таймеры не реализованы.
